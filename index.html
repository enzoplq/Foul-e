✨ IA intégrée (Claude)

L'IA crée des prépas entièrement sur mesure et les ajuste quand tu le demandes. Elle utilise ta propre clé API Anthropic (payante à l'usage, quelques centimes par prépa). La clé reste uniquement sur cet appareil. Sans clé, le coach intégré fonctionne quand même, gratuitement et hors ligne.

Obtenir une clé : console.anthropic.com → API Keys.

🟧 Strava

Sans connexion (gratuit, marche toujours) : Parcours → Envoyer vers Strava crée un fichier GPX à importer dans Strava (site web → Tableau de bord → Mes itinéraires → Créer un itinéraire → bouton d'import). Tes courses enregistrées dans l'onglet Live s'exportent en GPX horodaté à téléverser sur strava.com/upload/select.

💾 Sauvegarde

Les données de Safari et celles de l'appli sur l'écran d'accueil sont séparées : utilise la sauvegarde pour passer de l'un à l'autre, ou pour changer d'appareil.
